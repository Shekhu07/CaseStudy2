# Dry run — the prototype survey, answered as three personas

> ## ⚠ SYNTHETIC. NOT DATA.
>
> These answers are **invented**, by me, from `prototype-panel-personas.md` and
> `persona.md`. They are a pilot of the instrument — a check that every question
> in `create-prototype-usability-form.gs` yields something the metric table can
> use, and a preview of how the numbers would read — and nothing else.
>
> **They must never enter the response sheet, a chart, a percentage, or the
> deck.** If a number in the final submission cannot be traced to a real
> respondent, it does not go in. This file exists to be thrown away once real
> panel responses land. Same convention as `persona-dry-run.md`, which does the
> equivalent pilot for `wishlist-survey.md`.

Three respondents, chosen for coverage, not variety — see
`prototype-panel-personas.md` for why these three and not a fourth:

| Persona                                               | Tests                                                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Aditi-shaped** — fit-uncertain                      | Does the fit signal actually resolve her doubt, or just restate it?                               |
| **Rohan-shaped** — low-trust                          | Does the module carry a trust signal at all, or is it fit-only?                                   |
| **The comparer** — buys none of several close options | Does the Compare/pairing screen resolve indecision, the one behaviour Aditi and Rohan never test? |

## If these three were the whole panel (illustrative only — n=3, not evidence)

| Metric                                                 | Value at n=3                             | Target                                                      |
| ------------------------------------------------------ | ---------------------------------------- | ----------------------------------------------------------- |
| Reconnection success rate (Q2, "easily"+"had to look") | 3/3 = 100%                               | none set                                                    |
| Comprehension rate (Q3, "Yes, clearly")                | 2/3 = 67%                                | **≥ 80%** — misses it, driven entirely by Aditi's "Sort of" |
| Mean confidence (Q5)                                   | (3+3+4)/3 = 3.33                         | none set                                                    |
| Mean doubt-resolution (Q7)                             | (2+2+3)/3 = 2.33                         | none set — but visibly weak                                 |
| "Good enough to decide" (Q6)                           | 0/3 = 0%                                 | none set — all three still want to check elsewhere          |
| Q10 split                                              | 1 fit / 1 trust / 1 outside the taxonomy | contradiction check #1 — even split is itself informative   |
| Compare helped (Q14, of those who compared)            | 1/1 = 100%                               | none set                                                    |
| Overall usefulness mean (Q16)                          | (3+2+4)/3 = 3.0                          | none set — the CS1 test                                     |

**The one real finding this dry run surfaces:** every persona's Q6 lands on
"helped, but I'd still check elsewhere" — nobody hits "good enough to
decide." At n=3 that's a coincidence of how I wrote the answers, not a
result. But it's worth watching for in real data, because if it holds at
panel scale, it's the sharpest possible falsification of the module: it
finds the item, it's moderately confident-inducing, and it still doesn't
close the loop.
